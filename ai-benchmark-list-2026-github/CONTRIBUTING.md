# Contributing

Thank you for helping maintain this benchmark list.

## Link update guidelines

When adding or updating a benchmark link, prefer sources in this order:

1. Official benchmark website or leaderboard
2. Official GitHub repository
3. Paper page, such as arXiv
4. Reputable institutional page

## Entry format

Each benchmark entry should include:

- Benchmark name
- Primary category
- Official or primary URL
- Short description in English, Chinese Simplified, and Japanese

## Scope

This repository focuses on AI evaluation benchmarks for:

- LLM knowledge and reasoning
- AI agents and real-world task execution
- Tool use and MCP
- Coding and software engineering
- Data analysis, office work, and research
- Web, PC, and browser operation
- Multimodal, video, and long-context evaluation
- Safety, cybersecurity, and healthcare

## Style

Keep descriptions short and neutral. Avoid ranking claims unless they are clearly supported by a cited source.
